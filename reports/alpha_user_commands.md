# Alpha User Commands (Friend & Family)

Safe commands for non-technical testers. Say or type these exactly (or close variations).

## Screen & desktop

| Say this | What it does |
|----------|----------------|
| `what is on my screen` | Describes what JARVIS sees on your screen |
| `summarize this screen` | Short summary of the current screen |

## Web browser

| Say this | What it does |
|----------|----------------|
| `open website example.com` | Opens a website (use a normal site you trust) |
| `search web for weather today` | Searches the web for a topic |
| `summarize current page` | Summarizes the active browser tab |

## Memory

| Say this | What it does |
|----------|----------------|
| `remember that my meeting is at 3pm` | Saves a note for this session |
| `what do you remember about meeting` | Recalls saved notes |

## Daily summary

| Say this | What it does |
|----------|----------------|
| `summarize my day` | Calendar-style summary (mock/read-only in alpha) |

## Voice test

| Say this | What it does |
|----------|----------------|
| `test real voice conversation` | Records mic, transcribes, speaks a short reply (evidence logged) |

## Session control

| Say this | What it does |
|----------|----------------|
| `stop listening` | Ends the current voice listening session |

## Setup & status (optional)

| Say this | What it does |
|----------|----------------|
| `alpha setup check` | Runs first-run checklist (PASS / FAIL / ACTION REQUIRED) |
| `show alpha report` | Summary of your alpha session usage |

## Not available in alpha

- Deleting files or memory without developer approval
- Sending emails or messages
- Trading / live loops / investigation alerts (hidden unless critical)
- Changing system settings or autostart
- Typing passwords or making purchases

If something is blocked, you will see: **Alpha safety: this action is blocked for friend & family testing.**
