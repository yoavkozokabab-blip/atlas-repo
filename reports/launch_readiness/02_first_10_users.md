# 02 — First 10 Users Plan

**Date:** 2026-06-20. ICP = **developers already using an AI coding agent (Claude Code/Desktop, Cursor, Codex) on a real Windows repo**, who feel the "my AI keeps losing context / guessing at my codebase" pain. Atlas is an MCP that feeds them better context — so the audience is exactly "people who already use these tools."

## Goal for the first 10
Not growth — **learning + proof**. 10 *supervised*, high-signal users who will (a) complete the install→connect→first-answer journey, (b) tell you exactly where they got stuck, (c) say whether the answer was actually useful. Avoid broad/anonymous channels this early (Windows-only + unsigned + no polish = noisy failures, no feedback).

## Source evaluation
| Source | Expected conversion | User quality | Feedback quality | Risk | Notes |
|---|---|---|---|---|---|
| **Personal network / warm intros** | High | High | **Very high** (they'll talk to you) | Low | Best for first 3–5; you can screen-share |
| **r/ClaudeAI, Cursor Discord/forum, Claude Code users** | Med | High (exact ICP) | High | Med | Value-first, not spam; DM willing testers |
| **X (devtools/AI-coding circles)** | Low-Med | High | Med | Med | Reply-guy + a "looking for 10 testers" post |
| **Codex / OpenAI dev communities** | Med | High | High | Med | Same MCP value prop |
| **IndieHackers** | Low | Med | High (builders give feedback) | Low | Good for builder empathy, low volume |
| **Discord (AI-dev servers)** | Med | High | High | Med | Real-time debugging with users |
| **LinkedIn** | Low | Med | Low | Low | Slow, formal; weak for devtools |
| **Reddit r/programming, r/ExperiencedDevs** | Low | Mixed | Low | **High** (harsh, anti-promo) | Avoid until polished |
| **Hacker News** | — | High | High | **Very high** | NOT for first 10 — see HN doc |

## Ranking (do in this order)
1. **Warm intros / personal network** (users 1–3) — screen-share the install, watch every confusion point.
2. **Claude/Cursor/Codex power users via DM** from r/ClaudeAI + Cursor Discord (users 4–8) — recruit explicitly: "I built an MCP that gives Claude your repo's real structure — want to try it and tell me where it breaks?"
3. **IndieHackers / a single X post** (users 9–10) — builders who give structured feedback.

## Recruiting message (template, not spam)
> "If you use Claude Code / Cursor / Codex on Windows: I built Atlas, a local MCP that gives your agent the right files/symbols for a task (no code leaves your machine). Looking for ~10 testers for a free invite beta — 15 min to set up, I'll personally help. Interested?"

## Success bar for the cohort
- ≥7/10 reach "Claude used Atlas and found the right files."
- ≥5/10 do a 15-min interview.
- Collect the top 3 friction points and the top 3 "wow" moments.
