# Syron Rebrand — Phase 7: Social & Marketing Prep

Recommended public-facing copy for the **Syron** brand (repository intelligence).

## Website title
**Syron — Repository Intelligence Platform**

## Slogan
- Primary: **"Understand any codebase before you change it."**
- Alternates:
  - "Repository intelligence for you and your AI."
  - "Map the code. Then move fast."

## Meta description (SEO, ~155 chars)
> Syron is a local-first repository intelligence platform. It maps architecture,
> dependencies, risk and impact, then exports grounded context for Claude, Codex
> and Cursor.

## LinkedIn company description
> Syron is a local-first repository intelligence platform that helps engineering
> teams and their AI coding assistants understand large codebases instantly.
> Syron scans a repository's architecture, dependencies, risk and change-impact,
> then compresses it into a grounded context packet — so every investigation,
> impact analysis and AI prompt starts from facts, not guesses. Your code never
> leaves your machine.

## GitHub organization description
> Local-first repository intelligence — architecture, dependency graphs, impact
> analysis and grounded AI context for any codebase.

## X (Twitter) bio (≤160 chars)
> Local-first repository intelligence. Map architecture, dependencies, risk &
> impact — and give your AI assistant grounded context. Your code stays local.

## Naming guidance (consistency)
- Product name: **Syron** (never "the Syron", never all-caps in prose except logos).
- Product line: **Syron Repository Intelligence**.
- Attribution: **"Built with Syron"**.
- Internal package/identifier names (`jarvis_desktop`, `atlas_knowledge`,
  `ATLAS_*` env vars, `atlas://` catalog URIs) are **not** brand surfaces and are
  intentionally unchanged — see the validation report.
