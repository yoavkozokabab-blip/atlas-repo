# Creative Direction — Atlas Public Website

## One concept: **Atlas — The Living Map**

Atlas's own name is the idea. An atlas is a *cartography of knowledge*; the product turns a
repository — a dark, disconnected scatter of files, symbols and concepts — into a **navigable,
labeled, persistent map that stays alive across sessions.** Not a dashboard. An intelligence
layer that lives *underneath* the coding workflow and remembers.

We commit to this single concept. Everything (copy, 3D, motion, layout, product UI) serves it.

### The through-line the user must feel

1. A repository is entropy: fragments with no memory. Every AI session re-explores from zero.
2. Atlas **maps** it — files, symbols, concepts and the relationships between them.
3. The map **crystallizes into a persistent memory core** that survives across sessions.
4. Coding agents (Claude Code, Cursor, Codex) **retrieve** cited context from that map.
5. The map **stays current** as the repo changes.

The whole site is one continuous descent *through Atlas's understanding of a project* —
beginning in complexity, resolving into structure, ending on a single precise Atlas mark.

### Signature visual language

- **The Constellation** — a restrained 3D graph of nodes (files/symbols/concepts) that begins
  as dim noise and *crystallizes* into structured clusters bound to a central **memory core**.
- **The Contour Grid** — a near-subliminal topographic/isoline texture (real atlases use
  contour lines). It is the connective tissue between the void and the graph; it says *map*
  without a single literal map icon.
- **The Core** — a persistent, quiet nucleus. Not a glowing orb; a dense, faceted lattice that
  holds the resolved memory. It is the one thing that never disappears on scroll.
- **Cited evidence** — mono-type file paths and relevance scores are treated as first-class
  visual objects, not decoration. Atlas's credibility *is* the citation.

### Emotional target

Cinematic, intelligent, precise, restrained, confident. The feeling of an instrument, not an
app. Within ~5 seconds a developer should understand: *persistent memory of my codebase, for my
coding agent, that stays on my machine.*

### What this is NOT (hard bans — see visual-system + prohibited list)

No blue-purple hero gradient. No glowing orb. No random particles. No glass cards everywhere.
No three-card feature grids as the primary rhythm. No browser-frame screenshot mockups. No
spinning cube/globe. No decorative neural-net graphic. No fake terminals, chats, testimonials,
logos or invented metrics. Every 3D element maps to a real product stage or it is cut.

## Positioning & voice

**Positioning:** *Persistent, local-first repository memory for AI coding agents.* Atlas indexes
a repo into a dependency graph + evidence store and serves cited context to Claude Code, Cursor
and Codex over MCP — and that memory persists across fresh agent sessions.

**Voice:** technical, direct, honest, quietly confident. Developer-to-developer. Radical
technical honesty over marketing. Real numbers only (see content-plan.md).

**Headline (chosen):** *Your codebase, remembered.*
**Support line:** *Atlas maps your repository into a persistent memory and serves cited context
to Claude Code, Cursor and Codex — locally, across every session.*
**Primary CTA:** Download Atlas · **Secondary:** See how it works / View on GitHub.

## The seven review lenses (applied after every section)

Creative director · Product designer · WebGL engineer · Motion designer · Accessibility
reviewer · Performance reviewer · Developer judging product credibility. Each must find and log
specific issues in `visual-qa-checklist.md` before a section is called done.
