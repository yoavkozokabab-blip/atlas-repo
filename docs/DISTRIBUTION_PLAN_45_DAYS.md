# Atlas — תכנית הפצה 45 יום (שעה ביום)

> מטרה: **300+ משתמשים רשומים/מותקנים** (לא בהכרח משלמים) תוך 45 יום, בהשקעה של ~שעה ביום.
> הערכת הסתברות כנה: ~85-90% ליעד של 300, ~60% ליעד של 500. אין 99% בשיווק — יש הטיית סיכויים.

## הגדרת "לקוח" (מה סופרים)
משתמש רשום באתר **או** התקנת דסקטופ **או** חיבור MCP פעיל. הכל כבר נמדד היום (אדמין + analytics מקומי). מדד עומק: משתמש שסרק ריפו לפחות פעם אחת.

## למה 45 יום ולא 30
- ערוץ ה-MCP directories הוא ההימור הבטוח ביותר (תנועה עם כוונת-שימוש, evergreen) — אבל לוקח 1-3 שבועות עד שהרישומים מתאשרים ומתחילים להביא תנועה יציבה.
- שני אירועי השקה (Show HN + Product Hunt) עם שבוע פידבק ביניהם מכפילים סיכוי לפגיעה אחת טובה.
- בסיס הנתונים: עמוד ראשון ב-HN = ‏5-30 אלף מבקרים ביום; המרה טיפוסית לכלי-דב 2-5%. בלי עמוד ראשון: מאות מבקרים בודדות. מתכננים כאילו אין עמוד ראשון — עמוד ראשון זה בונוס.

## תנאים מקדימים (שבוע 0 — לפני שהשעון מתחיל)
בלי אלה אין למי להגיע. חד-פעמי, ~4-6 שעות מצטבר, רובו כבר מוכן בריפו:
1. **אתר חי** על Vercel + Supabase מחוברת (מדריכי click-by-click כבר כתובים ב-docs/).
2. **GitHub Release** ציבורי עם Atlas_Setup.exe + SHA256, ו-ATLAS_INSTALLER_URL מוגדר.
3. **דומיין** (useatlas.dev) מחובר.
4. **חתימת קוד** — SmartScreen הורג המרות התקנה על Windows. אופציות: Azure Trusted Signing (~$10/חודש) או הבלטת מסלול "run from source / MCP" למי שנרתע. זה הגורם המכריע ביותר בהמרת הורדה→התקנה.
5. **מסלול ללא-Windows**: עמוד docs קצר "Run the Atlas MCP server from source" (py -3 run_atlas.py --mcp) — פותח את קהל ה-Mac/Linux בלי לבנות אפליקציה.
6. חשבון X/Twitter + חשבון Reddit עם קצת קארמה (להתחיל להגיב שבוע לפני שמפרסמים).

## החלוקה היומית של השעה
- ~15 דק': מענה לתגובות/פידבק בכל הערוצים (Reddit/HN/X/מייל). זה מכפיל-הכוח הכי גדול.
- ~40 דק': משימת היום מהתכנית.
- ~5 דק': עדכון מספרים בטבלת מעקב (ביקורים, הרשמות, התקנות, סריקות).

## שבוע 1 (ימים 1-7): תשתית הפצה evergreen

- **יום 2:** הגשה ל-4 ה-directories: mcp.so, smithery.ai, glama.ai/mcp, pulsemcp.com (+ claim ownership בכולם).
- **יום 3:** PR ל-punkpeye/awesome-mcp-servers (התנועה הכי איכותית בתחום) + Cursor Directory.
- **יום 4:** הקלטת דמו 60-90 שניות: "שאלה על ריפו של 25 אלף קבצים → תשובה מדויקת עם קבצים". להעלות ל-YouTube + לחתוך ל-2 קליפים.
- **יום 5:** עמוד docs "Quickstart ללא Windows" + בדיקה שהתקנה מלאה עוברת חלק על מכונה נקייה.
- **יום 6:** פוסט X ראשון (build in public): הבעיה → הפתרון → GIF. + הצטרפות ל-Discord של Cursor, Anthropic MCP, r/ClaudeAI.
- **יום 7:** טבלת מעקב KPI + baseline. בדיקת שבוע: כל הרישומים הוגשו? אם לא — להשלים.

- **ימים 19-20:** תיקון 2-3 דברים שה-HN crowd העיר עליהם. לפרסם changelog קטן — זה מייצר גל שני.

## KPI שבועי (עוצרים ומתקנים אם חורגים)
- שבוע 1: כל הרישומים הוגשו. שבוע 2: ‏40+ נרשמים. שבוע 3: ‏120+. שבוע 4: ‏180+. יום 45: ‏300+.
- משפך למעקב: ביקור → הרשמה (יעד 8-12%) → התקנה/חיבור MCP (יעד 50%+) → סריקה ראשונה (יעד 70%+).

## סיכונים עיקריים
1. **SmartScreen (לא חתום)** — הפוגע מס' 1 בהמרה. פתרון: Azure Trusted Signing או דחיפת מסלול MCP-from-source.
2. **Windows-only** — חוסם ~60% מקהל המפתחים. פתרון: מסלול MCP מקוד-מקור (יום 5) + "macOS interest" בטופס העדכונים הקיים.
3. **תחרות מובנית** (Cursor/Cline מכילים אינדוקס משלהם) — המסר חייב להיות הבידול: local-first, evidence-backed, עובד על כל הסוכנים, לא נועל אותך לעורך אחד.
4. **פוסט שנופל** — לכן יש 6+ יריות שונות ולא אחת.
