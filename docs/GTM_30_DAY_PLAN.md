# 30-Day Go-To-Market Plan

**Goal:** first real users + first paying pilot. Solo founder. Honest note: a true paid
customer in 30 days requires billing wired (Day 25) and is more likely a signed pilot/LOI
than self-serve revenue. Public launch steps assume a signed installer + green
[GitHub public checklist](GITHUB_PUBLIC_CHECKLIST.md) first.

Format: Day — Objective — Tasks — Output — Metric.

## Week 1 — Foundation + first partners
1. Reposition — finalize README/landing one-liner — published — coherent message live.
2. Target list — 30 multi-agent/large-repo devs — list — 30 names.
3. Demo — 2-min video (scan→ask→evidence→token count) — asset — video done.
4. Benchmark — publish retrieval benchmark (method + honest numbers + where it loses) — post — live.
5. Outreach — DM first 8 prospects (personal, no deck) — outreach — 3 calls booked.
6. Quickstart — setup doc + sample config — asset — copy-paste setup exists.
7. Onboard — 2 design-partner calls, hand-onboard (screen-share) — onboarding — 2 active.

## Week 2 — Content + more partners
8. Onboard 3 more partners — onboarding — 5 active.
9. FAQ + objections — asset — published.
10. LinkedIn post (demo + benchmark chart) — distribution — inbound.
11. Reddit (r/ChatGPTCoding) practical post — distribution — installs/comments.
12. Triage feedback; fix top friction; log every founder-assist — iteration — 1 fix shipped.
13. Example repos + "first query" prompts — asset — examples live.
14. Decide OSS-core scope; prep public repo — decision — checklist green.

## Week 3 — Public launch (only if signed + checklist green)
15. Soft launch in 2–3 niche Discords — distribution — installs, activation rate.
16. Engage every reply; hand-onboard inbound — support — activation logged.
17. Show HN (lead with honesty + benchmark) — distribution — signups.
18. Twitter/X thread (demo + effect-size chart) — distribution — reach.
19. Ship #1 requested fix — iteration — responsiveness signal.
20. Cold + warm outreach to 20 large-repo teams citing benchmark — outreach — 3 calls.
21. Buffer / rest (burnout guard) — sustainability — triage only.

## Week 4 — Convert
22. 3 enterprise/team discovery calls — research — pains + WTP.
23. Pricing test: ask retained users what they'd pay; collect LOI — pricing — verbal commits.
24. Ship most-requested fix from week 3 — iteration — shipped.
25. Wire real Paddle OR manual invoice for first willing payer — monetization — payment possible.
26. Close 1–2 paid pilots / signed intents — revenue — first $ or LOI.
27. Referral asks + testimonials — growth — 2 referrals.
28. Retention check: who's active at 7+ days? interview 3 churned — measurement — retention number.
29. 30-day retro: funnel, top friction, next focus — analysis — written retro.
30. Decide: continue / fix-and-relaunch / reassess — decision — go/no-go.
