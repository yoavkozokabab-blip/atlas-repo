            About Atlas
            
      
            What Atlas does
            
      
              
        
            • Scans your codebase locally — files, modules, imports, and dependency edges
              • 
        
            • Maps architecture and risk in an interactive Codebase Map
              • 
        
            • Produces grounded Repository Analysis, Implementation Plans, Failure Investigations, and Change Impact reports
              • 
        
            • Packages repository evidence for Claude, Codex, and Cursor
              • 
        
            • Stores feedback and diagnostics on your device for support
              • 
      
            
      
            What Atlas does not do
            
      
              
        
            • Does not upload your source code to the cloud for analysis
              • 
        
            • Does not apply patches, run git commands, or edit files automatically
              • 
        
            • Does not replace your IDE, test runner, or production monitoring
              • 
        
            • Does not guarantee a single correct root cause — failure investigations rank hypotheses with verification steps
              • 
        
            • Does not require an API key for core repository scanning
              •

            See what may break before the code changes
            
        
            Atlas maps your repository into a dependency graph with persistent memory, so you — and your coding agent — can check the likely blast radius of a change before making it.
            
      
            

      
            
        
            Local-first. Your code stays here.
            
        
            Scanning, analysis, and memory all run on this machine. No account is needed — you are in guest mode right now, and that is a fully working mode.
