Getting started

Documentation

Atlas is a local-first repository intelligence desktop product. The workflow is intentionally simple.

1. Choose a repository

Open Atlas and select a local repository folder. Validate the path before starting the scan.

2. Scan locally

Atlas builds a repository map, dependency graph and evidence-backed intelligence surfaces on your machine.

3. Ask and connect

Ask Atlas repo-aware questions, then connect Claude, Cursor, or Codex through MCP-backed repo memory.

Documentation is intentionally concise. It will expand as external workflows stabilize.
