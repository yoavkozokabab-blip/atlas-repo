Quickstart — from zero to a repo-aware answer in 5 minutes

Atlas maps your codebase locally, answers repository questions with cited files, and prepares grounded context you can paste into Claude, Cursor, or Codex. It does not edit your files.

The 5-minute path

  1. Open Atlas. Your browser opens automatically to the Home screen.
  2. Click “Load sample repository.” No folder path, no setup — Atlas indexes a bundled sample repository.
  3. Land on Ask Atlas. Atlas pre-fills “What breaks if I change services/auth.py?” so you can send a real repo question immediately.
  4. Read the cited answer. Atlas shows relevant files and evidence from the local repository map.
  5. Use Plan Change when you are ready. Describe a change to get affected files, implementation order, risks, and tests.

Scanning your own repository

  • ✓ Recommended — choose your project root, the folder that holds your source code.
  • ✗ Avoid — node_modules, .git, your whole C: drive, Desktop/Downloads, or external_repos.
  • If a folder looks too broad, Atlas warns you before scanning and lets you choose a smaller folder or continue anyway.

What the words mean

  • Ask Atlas — repo-aware answers with cited files.
  • Plan Change — files, order, risks, and tests for a change you describe.
  • What breaks? — which files import your target and may break if you change it.
  • Codebase Map — an interactive 3D view of modules and dependencies.
  • Send to AI — copy a ready prompt for Claude, Cursor, or Codex.

Install notes

  • Windows — launch Atlas from the Start menu or desktop shortcut.
  • No Python required if you installed with Atlas_Setup.exe — everything is bundled.
  • Source mode needs Python 3.10+: run py -3 run_atlas.py (Windows) or python3 run_atlas.py (macOS/Linux).
  • Unsigned build — Windows SmartScreen may warn on first launch because Atlas is not yet code-signed. Click More info → Run anyway to continue.
