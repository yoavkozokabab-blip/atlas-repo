Changelog

Atlas is moving quickly. This page records public-facing product changes.

1.0.0 — June 2026

Windows release. This build gives developers local-first repository intelligence for AI coding tools.

  • Trust integrity — every Ask Atlas answer, Plan Change result, Debug result, and What Breaks result is grounded in your actual repository graph. Atlas refuses to produce output it cannot support with evidence.
  • Repository memory — Atlas remembers your repository structure across sessions. Exports sent to Claude include a compact memory header (~120 tokens) instead of repeating the full context each time.
  • What breaks? — enter any file or module to see what depends on it before you edit. Reverse-import closure to depth 3 with risk classification.
  • Token reduction — minimal export is 97%+ smaller than sending your codebase directly. Memory delta mode reduces per-question overhead by 55–73% on large repositories.
  • Plan Change — describe a feature in plain English; Atlas names the files, order, and risks. Copy directly to Claude, Cursor, or Codex.
  • Debug — paste a symptom or error; Atlas ranks likely causes with verification steps grounded in your import graph.
  • Local-first — no source code leaves your machine. All analysis runs locally against a Python/TypeScript import graph built from your repository.

Current limitations

  • Python and TypeScript repositories are fully supported. Go, Java, Rust, and C# get file discovery but limited import graph resolution.
  • Repositories over ~50,000 files use a sampling strategy; some file links may not be resolved.
  • Windows is the supported platform. macOS and Linux are not supported yet.
