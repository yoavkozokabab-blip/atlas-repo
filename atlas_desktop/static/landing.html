FAQ

Questions, answered

Does Atlas replace Claude, Codex or Cursor? +

No — and it's not trying to. Atlas makes the tools you already use dramatically more effective by giving them a precomputed map of your repository: architecture, dependencies, risk and impact. Your agent spends its tokens reasoning, not re-reading.

Does my code leave my machine? +

Never. Atlas is local-first. It analyzes your repository on your computer, requires no cloud upload and no API keys, and produces deterministic results you can verify.

What languages does it support? +

The first release focuses on Python repositories, with the dependency graph, risk ranking and AI export tuned for them. More languages are on the roadmap.

How does it actually save tokens? +

Instead of your agent reading dozens of files to orient itself, Atlas hands it a compact, structured context packet — subsystems, hubs, risks and entry points — with citations. The agent starts informed, so it reads less and answers better.

Is this a finished product? +

The core analysis is real and runs today; we're polishing the experience and expanding coverage.
