Repository intelligence

About Atlas

Atlas is a local-first repository intelligence desktop product. It maps architecture, dependencies, risk and impact so developers and their AI coding tools begin with a grounded view of the codebase.

What Atlas does

  • Scans repositories on your machine — modules, imports, edges, and architectural risk
  • Visualizes structure in the Repository Map (module, architecture, and hierarchy views)
  • Produces grounded Ask Atlas answers, Plan Change guidance, Debug analysis, and What breaks? results
  • Exports markdown workflow bundles and compact AI context for Claude, Codex, and Cursor
  • Collects optional local feedback and diagnostics to improve the product

What Atlas does not do

  • Upload your source code to the cloud for core scanning (analysis is local-first)
  • Automatically edit files, run tests, or deploy changes
  • Replace your IDE, linter, CI, or production observability stack
  • Guarantee a single correct root cause — debug results are ranked hypotheses with verification steps
  • Require API keys for repository scanning (optional cloud features may be added later)

Why Atlas exists

Large repositories are expensive to understand repeatedly. Atlas prepares a compact, inspectable map before an AI assistant starts reading files and making claims.

Where the product is today

Atlas v1.0.5 is the current Windows candidate. The desktop app provides local-first repository maps, Ask Atlas answers, Plan Change guidance, Debug analysis, What breaks results, and AI-ready context for Claude, Cursor, and Codex.
