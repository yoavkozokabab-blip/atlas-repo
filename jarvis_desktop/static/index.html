          About Atlas

          What Atlas does

          • Scans your codebase locally — files, modules, imports, and dependency edges
          • Maps architecture and risk in an interactive Codebase Map
          • Generates grounded Change Plans, Investigations, and What breaks? analysis
          • Sends ready-to-use context to Claude, Codex, and Cursor
          • Stores feedback and diagnostics on your device for beta support

          What Atlas does not do

          • Does not upload your source code to the cloud for analysis
          • Does not apply patches, run git commands, or edit files automatically
          • Does not replace your IDE, test runner, or production monitoring
          • Does not guarantee correct root cause — investigations are ranked hypotheses
          • Does not require an API key for core repository scanning
