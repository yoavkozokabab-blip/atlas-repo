Support & diagnostics

Something went wrong, or you want to check Atlas? You're in the right place. Nothing here is uploaded — reports stay on your device unless you send them yourself. New users: start with Load Sample Repository on Home, then Generate your first Change Plan.

Install notes

  • Windows beta — Atlas ships as a Windows desktop app. Launch it from the Start menu or desktop shortcut.
  • No Python required (installer) — If you used Atlas_Setup.exe, everything is bundled. You do not need to install Python.
  • Source mode (developers) — If you run Atlas from source, you need Python 3.10+. Use py -3 run_atlas.py on Windows or python3 run_atlas.py on macOS/Linux.

Common fixes (beta)

  • App won’t start — Install Python 3.10+. On Windows use Launch Atlas.bat. On Mac/Linux use python3 run_atlas.py (not py -3).
  • pip install failed — Do not run the monorepo requirements.txt. Atlas desktop needs no pip packages for the built-in server.
  • Scan never finishes — Avoid scanning node_modules, .git, or .venv. Use scan scope on Home.
  • Empty or odd results — Try Load Sample Repository first; then Rebuild index below.
  • “It won’t write code” — Expected. Atlas plans and exports context; you or your AI assistant implements changes.
