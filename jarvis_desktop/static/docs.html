Getting started

Documentation

Syron is a local-first repository intelligence desktop product. The beta workflow is intentionally simple.

1. Choose a repository

Open Syron and select a local repository folder. Validate the path before starting the scan.

2. Scan locally

Syron builds a repository map, dependency graph and evidence-backed intelligence surfaces on your machine.

3. Review and export

Inspect the graph, review impact and risk, then export compact repository context for your AI coding workflow.

Beta documentation is intentionally concise. It will expand as external workflows stabilize.
