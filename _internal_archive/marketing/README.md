# JARVIS — Launch & Social Kit

Everything needed to launch JARVIS to developers on X, Reddit, Hacker News and GitHub.

**The one-liner**
> Stop making AI read your entire repository. JARVIS builds architecture maps,
> dependency graphs, impact analysis and AI-ready context before Claude, Codex or
> Cursor ever see your code.

**Positioning (never drift from this):** JARVIS does **not** replace Claude/Codex/Cursor.
It makes them understand repositories **faster, cheaper, and with better evidence.**

| File | Use |
|---|---|
| `launch_copy.md` | Tagline bank, one-liners, elevator pitches, value props |
| `x_launch.md` | X/Twitter launch thread |
| `reddit_launch.md` | r/programming, r/webdev, r/ChatGPTCoding posts |
| `hackernews_launch.md` | Show HN title + body + comment-readiness checklist |
| `github_readme_screenshots.md` | README structure + screenshot checklist |

**Golden rules**
- Lead with the *problem* (AI re-reads your whole repo), not the feature list.
- Show, don't tell — a 15-second graph/scan GIF outperforms any paragraph.
- Be honest: "early, local-first, Python-first." Developers reward candor, punish hype.
- Always end with a single CTA: **Join the waitlist.**
