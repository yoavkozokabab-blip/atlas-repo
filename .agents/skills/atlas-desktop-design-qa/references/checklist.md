# Atlas desktop verification checklist

## Screenshots

- launch, failure, unsigned notice
- sign in, registration, local mode
- Home empty, ready, stale, productive
- repository selection, validation, scan progress, cancel, success, failure
- Memory, Files, Ask empty/loading/result/error/low confidence
- Impact, Debug, Plan empty/result/error
- Graph default, selected, list fallback, large repository
- Agents disconnected/connected/test failure
- Diagnostics healthy/degraded; Settings
- 900x650, 1280x720, 1440x900, 1920x1080

## Regression

- account session restore, local mode, and protected route gate
- validate/estimate/select/scan/status/cancel/resume
- persisted restore in a fresh process
- Ask/Impact/Debug/Plan rendering and history
- Graph views, selection, inspector, list fallback
- Claude Code, Cursor, Codex status/config/test/manual repair
- unrelated MCP servers and backups preserved
- diagnostics, support bundle, cache clear, rebuild confirmations
- account, device, billing-disabled, admin-role behavior
- startup failure, shutdown, updater, packaged assets

## Accessibility

- keyboard-only walkthrough and visible focus
- one active workspace heading and logical landmarks
- status text plus color
- progress/result announcements
- graph equivalent and selection announcement
- no trap; focus returns from overlays
- 200% zoom and reduced motion

## Product truth

- no fake data or decorative technical metric
- every claim traceable to an API field
- unknown, partial, stale, and low-confidence remain visible
- local-first copy does not overclaim connected-provider privacy
- source-only checks are not installed-app proof
