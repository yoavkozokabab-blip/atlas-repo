# JARVIS Landing Page Asset Checklists

Use these when capturing marketing materials from JARVIS Desktop **Screenshot mode**.

## Screenshots checklist

- [ ] Home hero with demo pack cards
- [ ] Scan success screen with metrics
- [ ] Command Center galaxy graph (Screenshot mode, full bleed)
- [ ] Health Cockpit with animated metrics visible
- [ ] Module Inspector 2.0 with evidence list
- [ ] Copilot impact answer + graph blast radius highlight
- [ ] Architecture timeline panel

- [ ] Demo Mode badge visible (optional trust cue)

**Capture tips:** 1920×1080, dark room UI, enable **Screenshot** toolbar button, export **PNG** at 2×.

## Demo video checklist (60–90 s)

1. **Hook (0–10 s):** “Understand any codebase in minutes — locally.”
2. **Install / launch (10–20 s):** Desktop shortcut → browser opens
3. **Try Demo (20–35 s):** Small demo pack → graph wow moment
4. **Risk + impact (35–55 s):** Copilot question → hub blast radius
5. **Export (55–70 s):** Copy Claude context + Demo Bundle
6. **CTA (70–90 s):** “Scan your repo — no cloud upload.”
