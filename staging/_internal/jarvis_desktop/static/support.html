Support & diagnostics

Check environment status, fix common issues, and export a support bundle — no source code included. New users: start with Load Sample Repository on Home, then Build Plan.

Common fixes (beta)

  • App won’t start — Install Python 3.10+. On Windows use Launch Atlas.bat. On Mac/Linux use python3 run_atlas.py (not py -3).
  • pip install failed — Do not run the monorepo requirements.txt. Atlas desktop needs no pip packages for the built-in server.
  • Scan never finishes — Avoid scanning node_modules, .git, or .venv. Use scan scope on Home.
  • Empty or odd results — Try Load Sample Repository first; then Rebuild index below.
  • “It won’t write code” — Expected. Atlas plans and exports context; you or your AI assistant implements changes.
