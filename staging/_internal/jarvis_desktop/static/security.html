Trust and safety

Security

Atlas is a local-first beta product. This page describes the current trust posture without claiming a completed security certification.

Repository handling

Desktop analysis runs locally. Atlas is designed to inspect selected repositories without sending source code to a cloud analysis service.

Evidence over guesses

Repository intelligence is presented with supporting structure so developers can verify important claims before acting.

Report a concern

Use the contact page to report a security concern. Please do not include secrets or sensitive repository contents in the first message.
