# Atlas Windows Installer

Produces **`Atlas_Setup.exe`** — a self-contained Windows installer for first-time beta users.

## Requirements

- **Python 3.10+** on the build machine (same as runtime)
- **[Inno Setup 6](https://jrsoftware.org/isinfo.php)** (`ISCC.exe` on PATH)
- Windows 10/11

## Build

From `local_jarvis/`:

```powershell
.\installer_build.ps1
```

Output: `installer/output/Atlas_Setup.exe`

## What the installer does

- Copies Atlas (app, demo packs, launchers) to `%LocalAppData%\Programs\Atlas` or chosen folder
- Creates **Start Menu** shortcut **Launch Atlas**
- Creates **Desktop** shortcut (optional task, enabled by default)
- Registers **app icon** (`assets/jarvis.ico`)
- Adds **Uninstall** entry in Windows Settings → Apps
- Does **not** require cloud accounts or API keys

## First run (3-minute wow path)

1. Double-click **Launch Atlas** from Desktop or Start Menu
2. Click **Load Sample Repository** or **Guided Walkthrough**
3. Open **Support** from the top bar if anything fails
3. Explore the 3D graph, ask Copilot, export context

## Clean uninstall

Use **Settings → Apps → JARVIS Desktop → Uninstall**. Local analytics remain in `%USERPROFILE%\.jarvis_desktop` unless removed by the uninstall hook.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `ISCC not found` | Install Inno Setup and add `ISCC.exe` to PATH |
| Python not found at runtime | Install Python 3.10+ and ensure `py` launcher works |
| Port 8777 in use | Close other JARVIS instances or edit launcher port |

## Files

| File | Purpose |
|------|---------|
| `jarvis.iss` | Inno Setup script |
| `assets/jarvis.ico` | Application icon (generated by build script if missing) |
| `../installer_build.ps1` | Staging + compile orchestration |
